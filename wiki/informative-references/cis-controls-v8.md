# Summary

**CIS Controls Version 8** serves as an official Informative Reference for the NIST Cybersecurity Framework 2.0[^nist-cswp-29].

Prescriptive, prioritized set of 18 critical cybersecurity safeguards mapping directly to CSF Subcategories.

# Mapping Structure

Informative references provide technical control mappings to the outcome-oriented Subcategories in the CSF Core.
