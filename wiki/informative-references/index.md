# Informative references

NIST's OLIR mappings from subcategories to SP 800-53 Rev. 5, SP 800-221A, CIS Controls, ISO/IEC 27001 clause identifiers, CSF 1.1 and others, with the NIST IR 8477 relationship type recorded.

## Concepts

- [CIS Controls Version 8](cis-controls-v8.md) — Prescriptive, prioritized set of 18 critical cybersecurity safeguards mapping directly to CSF Subcategories.
- [NIST SP 800-53 Rev. 5](sp-800-53-r5.md) — Security and Privacy Controls for Information Systems and Organizations providing comprehensive catalog of controls mapped to CSF.
- [ISO/IEC 27001:2022](iso-iec-27001-2022.md) — International standard providing specifications for an Information Security Management System (ISMS) mapped to CSF 2.0.
