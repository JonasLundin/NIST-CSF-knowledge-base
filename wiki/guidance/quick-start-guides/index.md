## Concepts

- [NIST SP 1301: Creating and Using Organizational Profiles](creating-and-using-organizational-profiles.md) — SP 1301 explains how to develop Current State and Target State organizational profiles.
- [NIST SP 1305: Cybersecurity Supply Chain Risk Management (C-SCRM)](cybersecurity-supply-chain-risk-management.md) — SP 1305 provides guidance on implementing C-SCRM outcomes using the GOVERN and IDENTIFY functions.
- [NIST SP 1303: Enterprise Risk Management (ERM) Quick Start Guide](enterprise-risk-management-quick-start.md) — SP 1303 explains how to integrate CSF 2.0 cybersecurity risk management with ERM processes.
- [NIST SP 1308: ERM and Cybersecurity Workforce Quick Start Guide](erm-and-workforce-quick-start.md) — SP 1308 connects CSF 2.0 outcomes with the NICE Workforce Framework (SP 800-181).
- [NIST SP 1347: Informative References Quick Start Guide](informative-references-quick-start.md) — SP 1347 explains how to create, navigate, and apply OLIR informative references to CSF 2.0.
- [NIST SP 1299: CSF 2.0 Resource and Overview Guide](resource-and-overview-guide.md) — SP 1299 provides an overview of CSF 2.0 and guides navigating companion resources.
- [NIST SP 1300: Small Business Quick Start Guide](small-business-quick-start.md) — SP 1300 provides tailored cybersecurity guidance for small businesses and non-profits.
- [NIST SP 1353: Using Artificial Intelligence for CSF (IPD)](using-ai-for-csf-quick-start.md) — SP 1353 initial public draft on utilizing AI capabilities to assist CSF implementation and analysis.
- [NIST SP 1302: Using the NIST CSF Tiers](using-csf-tiers.md) — SP 1302 guides organizations in selecting and applying CSF implementation tiers.
