# Summary

The **NIST Cybersecurity and Privacy Reference Tool (CPRT)** provides access to NIST cybersecurity and privacy reference datasets in standardized, human- and machine-readable formats[^nist-cswp-29].

# Data Offerings
- JSON and CSV schemas for the CSF 2.0 Core.
- Dynamic cross-walk mappings to NIST SP 800-53, ISO/IEC 27001, and CIS Controls.
